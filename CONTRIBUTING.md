# Contributing

## Desarrollo

```bash
npm install
npm test
npm run test:e2e
```

## Normas

- No añadir dependencias externas a producción sin justificación.
- Mantener la app compatible con GitHub Pages.
- No romper los 1000 modelos ni sus validaciones.
- Toda funcionalidad nueva debe conservar móvil, accesibilidad y exportación.
- Actualizar README y CHANGELOG en cada release relevante.
